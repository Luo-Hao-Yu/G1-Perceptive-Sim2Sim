# 默认零速度状态反复抬脚的诊断

日期：2026-10-20（Asia/Shanghai）。本次仅做对照和记录，保留已验证通过的策略加载、朝向与路径控制。

**2026-10-21 更新：** 加入首帧真实深度图填满历史的修复后，当前版本启动零速已能站立，问题表现为行走后停止仍踏步。本页保留的是修复前版本的历史测试；当前原因和新的行走→停止对照请见 [行走后停步诊断](walk_stop_diagnosis.md)。

## 结论与证据

直接原因是当前 `model_40000.pt` 对应的运动策略在零速度命令下仍生成周期性迈步动作。关节目标随策略输出变化，机器人执行后左右脚交替离地。这是当前策略在 MuJoCo 中的零速行为；零前进、零转向并不保证策略输出固定站立姿态。

在平地关闭外层反馈，确保输入策略的速度命令 20 秒始终为 `[0,0,0]`；去掉前 2 秒的落地过渡，分析后 18 秒。对照均使用种子 42、匹配的 actor/encoder 两件套和当前相同的模型与控制配置。

| 条件 | 左 / 右脚离地次数 | 左 / 右脚最高底面高度 | 说明 |
| --- | ---: | ---: | --- |
| 新 40000，平地，反馈 off | 19 / 19 | 10.25 / 11.01 cm | 速度命令始终严格为零 |
| 新 40000，平地，反馈 path | 19 / 19 | 10.42 / 10.94 cm | 自动 yaw 约 −0.025～+0.043 rad/s |
| 新 40000，木板起点，反馈 off | 20 / 19 | 10.45 / 11.09 cm | 仍始终输入零速度 |
| 新 40000，木板起点，反馈 path | 19 / 19 | 10.73 / 11.23 cm | 起点平台名义高度为 0 |
| 旧 30000，平地，反馈 off | 0 / 0 | 两脚持续接地 | 相同环境下基本静止 |
| 新 40000，脚底初始即接地，off | 19 / 19 | 10.30 / 11.01 cm | 排除初始自由下落的必要性 |
| 新 40000，2.5 ms 物理步长，off | 20 / 19 | 10.66 / 10.96 cm | 8 个物理步保持 20 ms 控制周期 |

离地计数定义：脚底四个碰撞球中最低表面高于名义板面 5 mm，同时该脚与静态地形的总法向接触力小于 5 N，持续至少 60 ms。它用于区分实际抬脚与接触瞬间抖动，不是跨越评分。高度在物理接触状态计算，包含碰撞球半径；触地时少量负值来自软接触穿透。

新策略的单脚踏步主频约 1.06 Hz，左右脚高度负相关，呈交替迈步。严格零命令的平地条件下，策略的膝关节目标峰谷变化约 72°，实际膝角变化约 54°；这表明策略持续给出大幅周期目标，并非目标角不变时单纯由接触求解器把脚弹起。旧策略膝关节目标变化约 0.3～0.5°，未检测到脚离地。

## 已排查的其他因素

1. **朝向保持不是抬脚的必要触发条件。** 反馈 off 时仍有同样频率和幅值的动作。path 模式的少量自动转向会调整朝向，但没有解释新策略在严格零命令下的踏步。
2. **初始脚底确实悬空约 3.60 cm。** 默认 pelvis 高度为 0.793 m，默认关节姿态下脚底最低点约为 z=0.036 m，起点面为 z=0，因此开始时有一次落地。临时将 pelvis 调整为约 0.756997 m，使脚底开始就接地，周期踏步仍出现；不能把持续 20 秒的反复抬脚归因于这一次落地。
3. **不只是当前 5 ms 步长的数值振荡。** 控制周期不变，将物理步长减半后仍有类似动作。该实验不等于已排除所有动力学差异，但没有支持“单改步长就能消除”的解释。
4. **不需要粗糙板面或脚下间隙来触发。** 平地同样出现，而旧模型在相同环境可以静止。木板测试期间机器人位于起点附近，不能据此推断跨越行为。

## 原因边界与后续处理

已确认的事实是：切换到最新匹配导出的策略后，零速度行为由站立变为原地踏步。专项续训、AMP 动作先验、零速样本或站立相关奖励的变化可能与此有关，但本机没有训练源码及零指令的 Isaac 对照，因此没有把其中任何一项认定为最终训练原因。

服务器上可做直接对照：给新旧模型都持续输入零速度命令，记录足端高度和膝关节目标。如果 Isaac 中新模型也踏步，应重点检查零速度训练覆盖、静止时 AMP/运动奖励，以及站立姿态、关节速度、足端接触/离地惩罚的设置；如果训练端能静止，则继续核对影响新策略的观测、动作延迟与动力学差异。

若目标是“松开手柄后双脚基本不离地”，需要策略具备明确的静止行为：可以补充/强化零速站立训练，或使用经过验证的 23DoF 站立策略，并验证与运动策略的平滑切换。直接冻结动作、把输出清零或恢复默认姿态 PD 并不等于获得站立平衡控制，本项目的无策略姿态预览本身不能保持平衡。当前也不应为消除抬脚而直接换回跨板能力较差的旧模型。

原始指标见 [idle_diagnosis.json](idle_diagnosis.json)，每个控制周期的足端高度、接触力、速度指令和膝目标见 [idle_foot_trace.csv](idle_foot_trace.csv)。两份策略的权重哈希和本次场景哈希已记录，便于服务器复核。
